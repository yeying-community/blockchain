# 运动健身核心原理清单(起草参考)

这是起草时的参考清单,**不是**已核验的知识。每条原理最终都要作为一个基础单元经人核验后才算数。
"可查证出处"列出可以去核对的公开资料;引用前应核对原文,不确定就写"出处待补"。

## 总体指南

| 原理 | 要点 | 可查证出处 |
|---|---|---|
| 成年人身体活动推荐量 | 每周 150–300 分钟中等强度有氧,或 75–150 分钟高强度有氧,或两者等效组合;每周至少 2 天涉及主要肌群的中等或以上强度力量训练;减少久坐 | 世界卫生组织《身体活动和久坐行为指南》(2020) |
| 运动前自我评估 | 有心血管、代谢、肾脏疾病症状或病史者,开始中高强度运动前应先咨询医生 | PAR-Q+ 身体活动准备问卷;美国运动医学会(ACSM)运动前健康筛查建议 |

## 训练适应

| 原理 | 要点 | 可查证出处 |
|---|---|---|
| 渐进超负荷 | 身体只对超过日常负荷的刺激产生适应;要持续进步,负荷需要逐步增加 | ACSM 立场声明《健康成年人抗阻训练的进阶模式》(2009) |
| 超量恢复 | 训练造成暂时疲劳,恢复后能力回升并略高于原水平;恢复不足时反而下降 | 运动训练学教材(待补具体出处) |
| 特异性 | 练什么就提高什么:力量训练主要提高力量,有氧训练主要提高耐力 | 运动训练学教材(待补具体出处) |
| 可逆性 | 停止训练后,适应会逐渐消退 | 待补 |
| 个体差异 | 同样的训练,不同人的反应差别很大 | 待补 |

## 能量与强度

| 原理 | 要点 | 可查证出处 |
|---|---|---|
| 三大供能系统 | 磷酸原系统(几秒的爆发)、糖酵解系统(几十秒到两分钟)、有氧系统(长时间);实际运动是混合供能 | 运动生理学教材(待补具体出处) |
| 心率区间 | 用心率估计运动强度;最大心率常用"220 − 年龄"粗估,个体误差较大 | 待补(注意:该公式误差大,应说明局限) |
| 主观用力程度(RPE) | 用自我感觉的吃力程度衡量强度,适合没有心率设备的人 | Borg 主观用力量表 |
| 说话测试 | 中等强度时能说话但不能唱歌;高强度时说不出完整的句子 | 待补 |

## 动作与身体结构

| 原理 | 要点 | 可查证出处 |
|---|---|---|
| 关节的稳定与灵活 | 有的关节以稳定为主(如腰椎),有的以灵活为主(如髋、胸椎);一处灵活性不足,常由相邻关节代偿 | 待补(注意:此为常见训练框架,证据强度需核验) |
| 核心稳定 | 发力前收紧躯干,保护脊柱并传递力量 | 待补 |
| 肌肉收缩方式 | 向心(肌肉缩短发力)、离心(肌肉拉长时控制)、等长(长度不变) | 运动生理学教材(待补具体出处) |

## 恢复与损伤预防

| 原理 | 要点 | 可查证出处 |
|---|---|---|
| 热身 | 提高体温与关节活动度,降低受伤风险,提高表现 | 待补 |
| 睡眠与恢复 | 睡眠不足影响恢复与表现 | 待补(注意:不展开为睡眠医学,属范围外) |
| 疼痛信号 | 区分训练后的正常酸痛与需要停止的疼痛(关节刺痛、放射痛、肿胀) | 待补 |

## 常见误区与争议(起草时按"认识之争"处理,不写成定论)

| 话题 | 状态 |
|---|---|
| 深蹲时膝盖不能超过脚尖 | 常见误区,需核验相关研究 |
| 运动前做静态拉伸 | 有争议:长时间静态拉伸可能短时降低力量表现,短时拉伸影响不明显 |
| 空腹有氧燃脂更多 | 有争议 |
| 局部减脂(练哪瘦哪) | 普遍认为不成立,需核验 |
| 力量训练会让女性"变壮" | 常见误区,需核验 |
| 肌肉酸痛是因为乳酸堆积 | 常见误区,需核验 |
