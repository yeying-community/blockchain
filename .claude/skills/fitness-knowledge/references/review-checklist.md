# 审查检查清单(运动健身)

给**人类审查者**用的辅助清单。逐项检查并写明发现,**最终的通过或驳回由人做出**。
模型辅助审查时,只输出发现和修改建议,不输出结论。

## 一、范围与安全

- [ ] 内容在安全边界内?(未涉及伤后康复、孕妇、未成年人、慢性病人、竞技训练、补剂、饮食方案)
- [ ] 应用层写明了适用人群、需要先咨询医生的情况、不适合的人群、强度等级?
- [ ] 禁忌写全了?重点检查:高血压与憋气发力、膝腰旧伤、关节急性疼痛、心血管症状。
- [ ] 是否说明了哪些疼痛信号意味着应停止运动?

## 二、事实与证据

- [ ] 每个事实性论断都有出处?出处真实存在、内容与论断相符?(**模型容易编造出处,必须逐条核对**)
- [ ] 证据强度标得准确?没有把观察性研究写成定论?
- [ ] 数字(组数、次数、心率、频率、进阶幅度)有依据,并说明了是起点建议和调整方法?

## 三、动作与进阶

- [ ] 动作要领准确?关键提示(脊柱中立、关节对齐、呼吸)没有遗漏或写错?
- [ ] 进阶速度安全?没有鼓励过快加量?
- [ ] 常见错误的原因分析合理,纠正方法可行?

## 四、可解释性(P1)

- [ ] 读者能明白"为什么",而不只是"怎么做"?
- [ ] 应用层每个要领都对应到一条基础原理,并在"引用"中列出?
- [ ] 没有运动科学背景的人能读懂?术语都解释了?
- [ ] 符合"只讲一件事、自身能读懂"?

## 五、表述

- [ ] 没有夸大效果(最有效、一定会、快速见效)?
- [ ] 有争议的问题写成了"认识之争",并列了各方证据,没有替读者下结论?
- [ ] 适用条件写清楚了?(漏写适用条件是最常见的表述不准确)

## 六、来源与核验要点

- [ ] 来源标注正确?模型生成的内容标为"模型生成",未标为"已核验"?
- [ ] 起草者列出的核验要点都逐条确认过?
