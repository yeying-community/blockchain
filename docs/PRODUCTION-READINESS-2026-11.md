## 4. 阻断项排序(主网)

1. **独立第三方安全审计**——最大、不可自我替代。治理(#10 攻击面 5「全新、未审计」)、桥

2. **经济参数校准**——需真实测试网多周运行 + 对抗建模反校,否则增发/罚没/质押激励可能被套利。
3. **规模化 + 对抗 + 分区/混沌测**——当前只有单元/集成测 + fuzz-lite/cargo-fuzz;无长跑、无网络
   分区下的安全/活性验证、无治理洪流压测。
4. **自动 liveness 问责缺位**——许可制可接受(运营手动处置);开放网络下宕机/审查零成本。

## 7. 附录:外部审计作为「已接受风险」后的部署判断(应运营方要求)

运营方要求**暂时搁置**「无独立第三方审计」这一阻断(作为**自觉接受的风险**),据此重判。

**关键认识:搁置审计 ≠ 清除其余阻断。** 审计是「人工复核」类保证,可由运营方签字接受风险而暂缓;
但**经济校准**与**规模化/分区/混沌测试**是**经验性**缺口——无法靠「决定」消除,只能靠真实运行数据
补上。因此:

| 形态 | 搁置审计后的判断 | 仍需满足 |
|---|---|---|
| 受控 / 许可制生产(已知运营方、价值有界) | ✅ **可带风险部署** | §11 工程项(已备)+ 保守经济初值(用 `sim/CALIBRATION.md` 推荐,即便未完全校准)+ ≥4 可信验证人 + 监控告警开 + 远程签名器托管密钥 + 运营方书面接受 §10 边界(无自动 jailing / 无滚动升级 / 经济未校准) |
| 公开激励测试网 | ⚠️ 谨慎 | 上面 + 先在测试网跑 **经济校准**(本就应在测试网做,审计无关)+ 治理/桥对抗观察 |
| 高价值 / 开放去中心化主网 | ❌ **仍不建议** | 即便接受审计风险,**经济未校准**(可被套利)与**无规模化/混沌测**(安全/活性未经压)两项**经验性**阻断未除。这两项不是「决定」能豁免的。 |

**结论(搁置审计后)**:
- **可以**上**受控/许可制生产**(运营方带风险接受),工程与运维件齐备。
- **仍不可**上**高价值/开放主网**——阻断从「3 项」减为「2 项」(经济校准、规模化测试),但这两项必须
  用真实运行数据补齐,无法仅凭风险接受豁免。

**建议的最小落地路径(受控生产)**:① 用 `sim/` 保守推荐值定 genesis;② `testnet/` 起 ≥4 节点
跑数日观察增发/罚没/供应守恒与 `docs/ops/` 告警;③ 验证人用远程签名器 + 加密 keystore;④ 运营方
签署《已知边界接受书》(§10 + 本附录);⑤ 上线后持续用这段真实数据反校经济参数,经链上治理微调。

## 8. 复评:仅剩两项阻断的真实状态(2026-11,M230–231)

应运营方要求「确保能够推向生产部署」,对搁置审计后仅剩的两项**经验性**阻断逐项复核**真实现状**——
不是靠「决定」豁免,而是核定已有证据/基建把每项推进到了哪里,以及**还差什么**。结论:两项都比
§4/§7 的框定更接近可控,但**高价值/开放主网仍不建议**——剩余缺口是真实的,只是更具体、更可收敛。

### 8.1 经济校准 —— 从「未校准」降级为「有证据的保守初值 + 可治理迭代」

[`sim/CALIBRATION.md`](../../sim/CALIBRATION.md) 已不是空白:`sim/sweep.py` 对 **4 个可治理旋钮**
(`base_emission`/`slash_bps`/`delta_k_min`/`tau_dup`)在 **5 种子 × 2 场景**(诚实基线 / sybil+合谋)
做了敏感性扫描,给出**带证据表与取值理由**的主网 genesis 建议值,且 sim 的 ΔK 走与节点**同一契约**
(`delta_k.py` ↔ `engine`)。关键结论有据:满罚(`slash_bps=10000`)给最强威慑且 fake-pass 最低;
`delta_k_min` 绝不可低于 0.05(=0 时 fake-pass 飙到 0.69);`base_emission` 4–8 诚实 ROI 稳健正、
膨胀温和。**四个旋钮全部可经 M193–198 链上治理(双门槛)上线后调整**——M228/M229 已补齐 `propose/
vote` 的离线授权 CLI 与运行时提交路径,`./cmd propose/vote` 可端到端演示一次「改 `base_emission` →
增发随之变化」的治理闭环。

**仍差(诚实边界,见 CALIBRATION.md §103–115)**:① **交互效应**未测(只做了一次一旋钮,未做
二维网格,如低增发×高罚的联合区);② `decay_half_life_blocks`(M187 增发时间衰减)、桥接经济、
治理攻击、真实需求销毁曲线**未建模**;③ novelty 用随机单位向量代理,**未建模对 ΔK novelty 项的
对抗样本攻击**;④ 最根本:这是**方向性模型,非央行级标定**,结论对行为假设敏感,**必须与测试网/
受控生产的真实数据交叉校准**。

**判断**:对**受控/许可制生产**,「保守初值 + 治理可调 + 上线后用真实数据反校」是**安全且标准**的
路径——该项**不再是受控形态的阻断**。对**高价值/开放主网**,在真实经济数据与对抗观察积累前,仍存
**可被套利**的残余风险(尤其交互效应与对抗 novelty)——**仍是阻断,但已收敛为「需真实数据」而非
「从零建模」**。

### 8.2 规模化/混沌 —— 从「无」到「崩溃容错 + 安全停摆 + 恢复有演练」,但分区/拜占庭/长跑仍缺

`testnet/`(M210,4 验证人、生产级安全姿态)已提供收敛(`smoke.sh`)、备份/恢复 + 快照 fast-sync
(`recover.sh`)、升级演练。**M231 补 [`testnet/chaos.sh`](../../testnet/chaos.sh)**,实测通过:

- **崩溃容错**:`SIGKILL` 掉容错预算内的少数验证人,存活 >2/3 **继续出块且不分叉**(实测 f=1)。
- **崩溃恢复**:重启被硬杀的节点,**追回同一 head**(`store.rs` 每记录 `sync_all` → SIGKILL 留干净
  边界 → 净回放)。
- **失去法定数的安全停摆**:再杀一个使在线 < 法定数,链**停摆而非分叉**(实测高度冻结,供应守恒)。

**M232 补 [`testnet/soak.sh`](../../testnet/soak.sh)**:长跑稳定性 soak,每采样点断言活性(高度严格
递增)、不分叉/不漂移(跨节点区块哈希 **+ state_root** 一致)、供应守恒且**跨节点数值一致**、无内存
泄漏(RSS 增幅有界)、干净日志——实测 4 节点全绿、RSS 增幅仅个位数 %。**M234 加 `load` 模式**:每采样
从加密 keystore(M233)授权一笔**知识 tx** 并经 `submit-tx` 投到 bearer 门控写面(CLI 现发配置 token,
M234)——实测 **5/5 tx 被接受**、供应随增发增长(90M→102.5M)且全程守恒+跨节点一致、无泄漏、干净日志。
这**补上了"tx 负载下的长跑"**这项此前的空白。

**本轮再暴露一项真实活性边界(新增 §10.11)**:**绑定即验证人权力,无在运证明/无激活延迟/无权力爬坡**。
一笔 `bond` 会立刻把账户注入活跃验证人集(power=绑定额);若该密钥不运行节点且权力 >1/3,法定数**永久
不可达**、链停摆且**重启不可恢复**。实测:power=1×4 的链上,一个不运行节点的账户绑定 1000 即独占 >2/3
→ 全链冻结。**安全性不破**(不分叉、供应守恒),是**活性/经济模型**风险;锐利之处是无准入门槛。故 soak 的
负载用知识 tx(不动验证人集)而非 stake-op。这正是负载测**应当**暴露的东西。

**本演练暴露一项真实活性边界(新增 §10.10)**:失去法定数停摆期间保持在线的节点会对待定高度不断
换轮;法定数恢复后其轮次号**不经 gossip 与重启节点自动对齐**,存活节点仍卡住——**安全性始终不破
(不分叉、正确停摆),仅自动活性恢复不完整**;**全量重启**即恢复(实测重新收敛)。属共识线待修项
(轮次追赶),非安全缺陷。这正是混沌测**应当**暴露的东西——它从「未知」变成了「已知且有规避手段」。

**已有(复核后更正)**:**活体拜占庭 → 罚没**并非"只有单元测"——`equivocation_over_tcp_slashes_the_offender`
在**真实 TCP 套接字**上让一个冒充验证人的裸 peer 泛洪两张冲突 precommit,诚实节点经 wire 观测双签 →
产证据 → 入块 → 罚没并移出验证人集(另有 `slashes_an_equivocating_validator_through_the_certified_chain`
走认证链)。**M233** 让 `encode-*` 的 `--key-file` 直接吃加密 keystore 签名(removes 明文种子限制;附单测 +
实测从测试网 keystore 授权 stake-op)。**M234** 给 `node rpc`/`submit-tx` 加 `[rpc] auth_token` bearer 支持
(实测:带 token → 接受、无 token curl → 401),**打通 tx 负载 soak**(见上,5/5 tx 全绿)。

**M235 缓解 §10.11**:新增创世参数 `max_validator_power_bps`(`testnet/gen.sh` 设 3333=1/3),
`apply_block_inner` 拒绝任何会让**新**验证人超过该占比的绑定(创世/既有验证人豁免;折入 state_root;
候选块经 `filter_applicable_stake_ops` 过滤防停摆)。实测:启用后不运行节点的账户大额绑定**被拒**、链继续
出块。残余见 SECURITY.md §10.11(既有验证人后续增绑、默认禁用需显式启用、治理动态调参待做)。

**M236 验证完全加固许可制姿态**:`testnet/gen.sh --permissioned` 开 genesis-pinned mTLS
(`require_peer_certs`)+ RFC5705 通道绑定(`bind_channel`),叠加既有 peer-auth + TLS。实测该姿态下
`smoke`(收敛)、`chaos`(崩溃容错 + 安全停摆 + mTLS 重连恢复)、`soak load`(tx 经 mTLS gossip 落块、
供应守恒)**全过**——补上"加固姿态仅收敛过、未经混沌/负载"的空白。

**M237 关闭"加固姿态下的活体拜占庭"**:`equivocation_under_peer_auth_still_slashes`——honest 节点开
`require_peer_auth`,一个持**有效创世密钥**的拜占庭验证人完成认证握手后仍泛洪双签,链照常检测→罚没移除。
证明认证层拦不住"有合法密钥的内鬼",罚没(基于签名)仍生效;mTLS/通道绑定为传输层,不触碰罚没路径。

**M238 修复 §10.10 自动活性恢复**:节点在对端(重)连接时重发自己对待定高度各轮次的已签名投票,重启
节点由此跨重连对端见到 `f+1` 更高轮次投票并触发既有 L55 跳转,跳到活跃轮次。`chaos.sh` Phase B 现
**只重启被杀节点即自动恢复**(连跑两次,h13/h34 同链续接),不再需全量重启。无新的不安全跳转,仅重投
已签名自有票。

**仍差**:① **真正的网络分区注入**(iptables/tc 延迟·丢包,需 root,本环境不可做);② **超 loopback
规模 + 真实网络延迟**(当前全 loopback,数百区块级,非小时/天级或跨机)。

**判断**:对**受控/许可制生产**(少数可信验证人、可人工处置),崩溃容错 + 安全停摆 + 恢复演练 +
§10.10 的已知规避手段,配 `docs/ops/` 告警,**已构成可接受的运维基线**。对**高价值/开放主网**,
分区/活体拜占庭/长跑未压 + §10.10 活性恢复未修,**仍是阻断**。

### 8.3 复评后的部署决策(覆盖 §5/§7)

| 形态 | 判断 | 变化 |
|---|---|---|
| 受控 / 许可制生产(已知运营方、价值有界) | ✅ **可带风险部署** | 不变,但两项阻断的「残余风险」已更明确、可控:经济用保守初值 + 治理反校;混沌有演练 + §10.10 已知规避 |

审计,不是文档或单机演练能替代的。
