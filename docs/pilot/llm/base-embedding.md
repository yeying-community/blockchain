## 核心陈述

**嵌入**(embedding)把一段文字映射成一个固定长度的数字向量,使**意思相近的文字,向量也相近**。
这样,"找意思相关的内容"就变成了"找距离近的向量",可以用数学方法快速计算。

## 正文

### 向量里装的是什么

嵌入模型读入一段文字(一个词、一句话或一段文档),输出一串数字,例如几百到几千个。单个数字通常没有可解释的含义;
有意义的是**向量之间的相对位置**:训练让经常出现在相似语境、表达相似意思的文字,向量彼此靠近。

### 怎么比较远近

最常用的是**余弦相似度**(cosine similarity):看两个向量的方向是否一致,结果在 −1 到 1 之间,越接近 1 越相似。

### 对开发者意味着什么

1. **按意思搜索**:"怎么退款"和"我想把钱要回来"字面不同,嵌入却可能很近,这是关键词搜索做不到的。
   检索增强生成(RAG)的检索步骤通常就靠它。
2. **只能和同一个模型的嵌入比较。** 不同嵌入模型的向量空间互不相通;换了嵌入模型,所有已存的向量都要重新计算。
3. **"相近"是模型学到的相近,不一定是你要的相近。** 例如"我喜欢这个产品"和"我不喜欢这个产品"
   可能很相近(话题相同),否定、数字、专有名词的区别有时会被弱化。重要场景要用自己的数据测一测。
4. **太长的文字会被截断或平均化。** 嵌入模型也有输入长度上限;一大段文字压成一个向量,细节会被稀释,
   所以检索时通常先把文档切成较小的片段。

```python
def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    return dot / (math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b)))

q = embed("怎么申请退款")
for s in ["我想把钱要回来", "退货流程是怎样的", "今天天气不错", "我不想申请退款"]:
    print(f"{cosine(q, embed(s)):.3f}  {s}")
```

预期:前两句的相似度明显高于"今天天气不错";注意观察"我不想申请退款"——它的意思相反,相似度却可能很高,
这就是第 3 条说的局限。

## 适用范围与局限

- 适用:语义搜索、去重、聚类、推荐、检索增强生成的检索步骤。
- 不适用:需要精确匹配的场景(编号、代码标识符、精确的数字),通常要结合关键词搜索。
- 容易过时的部分:具体的嵌入模型、向量维度、输入长度上限。
