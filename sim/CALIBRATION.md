# 经济参数校准 / Economic Parameter Calibration

> 生产就绪评估 **#7**。目标:把白皮书 draft v0.10 的"未校准参数"变成**有证据支撑的主网
> genesis 建议值**,附方法、敏感性数据、取值理由与诚实边界。
>
> 数据来自 [`sim/sweep.py`](sweep.py) 的敏感性扫描(见 [`SWEEP.md`](SWEEP.md),可
> `python3 sim/sweep.py --md` 复现)。扫描对每格在 **5 个种子**上取均值以压制种子噪声
> (README 已警示结论对种子/行为假设敏感)。

## 方法

- **模型**:`sim/model.py` 的 agent-based 仿真(白皮书 B.3),200 epoch。ΔK 走与节点
  **同一契约**(`delta_k.py` ↔ `engine`),故结论可外推到链上行为(同一函数)。
- **扫描**:每次只动**一个**可治理旋钮,其余取默认,在两个场景下测:
  - **honest baseline**(40 诚实、0 攻击者)——测供应膨胀与诚实激励;
  - **sybil+collusion**(30 诚实 + 15 spammer + 10 人合谋环)——测攻击者威慑。
- **判据**:
  - 供应 200-epoch 增长倍数(越接近 1 越稳,过高=通胀);
  - **诚实净质押回报**(`honest ROI`,须 > 0,否则诚实者退出);
  - **攻击者净回报**(`attacker ROI`,须 **< 0 且有余量**);
  - **fake pass**(伪贡献通过率,越低越好)。
- **旋钮 ↔ 节点 genesis 映射**:`base_emission`(sim $COG)↔ `base_emission_micro`(×1e6);
  `slash_ratio`↔`slash_bps`(1.0=10000);`delta_k_min`↔`params.delta_k_min`;
  `tau_dup`↔`params.tau_dup`。

## 发现与建议

### base_emission(增发系数)→ `base_emission_micro`

| base_emission | 供应增长× | 诚实 ROI |
|---|---|---|
| 1 | 0.99× | **−0.04**(诚实者净亏,过低) |
| 2 | 1.06× | +0.05(勉强) |
| 4 | 1.20× | +0.22 |
| **8**(当前) | 1.48× | +0.58 |
| 16 | 2.05× | +1.28 |
| 32 | 3.18× | +2.70(通胀) |

**建议:主网保留 `8`(= `8_000_000` micro)作上限,`4` 作保守下限。** `≤1` 会让诚实贡献者
净亏(激励崩),`≥16` 供应 200-epoch 翻倍以上(通胀压力)。`4–8` 区间诚实 ROI 稳健正、
膨胀温和。**强烈建议同时启用 M187 的 `decay_half_life_blocks`**(本 sim 未建模):它随链龄
把增发曲线往下弯,相当于给"引导期高、成熟期低"的发行表,比单一常数更稳——建议半衰期取
与预期"引导期"相当的区块数(如目标 2–4 年出块数),上线后经治理按真实数据调。

### slash_ratio(罚没比例)→ `slash_bps`

| slash_ratio | 攻击者 ROI | 诚实 ROI | fake pass |
|---|---|---|---|
| 0 | **+0.11**(攻击有利可图) | +0.71 | 0.146 |
| 0.25 | +0.01(打平) | +0.68 | 0.364 |
| 0.5 | −0.10 | +0.65 | 0.403 |
| 0.75 | −0.21 | +0.63 | 0.420 |
| **1.0**(当前) | **−0.32** | +0.58 | **0.060** |

**建议:主网保留 `1.0`(= `10000` bps,全额罚没)。** 证据清晰:`0` 时攻击**有利可图**
(ROI +0.11);威慑在 0.25–0.5 间转负;**满罚(1.0)给最强威慑(−0.32)且 fake pass 最低
(0.06)**——满罚让 spam 不划算到压制了尝试本身,而诚实 ROI 仅从 0.71 轻微降到 0.58
(仍强正)。满罚无诚实成本、收益最大,是干净的"保留默认"结论。若需降低诚实者误罚风险,
下限不应低于 `0.5`(低于此攻击者转为盈利)。

### delta_k_min(ΔK 质量门)→ `params.delta_k_min`

| delta_k_min | fake pass | 攻击者 ROI | 诚实 ROI |
|---|---|---|---|
| 0 | **0.689**(无门,大量垃圾过关) | −0.13 | +0.66 |
| **0.05**(当前) | 0.060 | −0.32 | +0.58 |
| 0.1 | 0.000 | −0.47 | +0.42 |
| 0.2 | 0.000 | −0.70 | **−0.10**(门太严,诚实者失败) |
| 0.4 | 0.000 | −0.87 | −0.38 |

**建议:主网保留 `0.05`;若要零 fake-pass 可取 `0.1`(代价:诚实 ROI 0.58→0.42)。** 这是
最敏感的旋钮:`0` 时 fake pass 飙到 **0.69**(门形同虚设),`≥0.2` 把诚实贡献也挡在门外
(诚实 ROI 转负)。`0.05–0.1` 是明确的甜区,当前默认 `0.05` 位置良好。**绝不可低于 0.05。**

### tau_dup(近重复阈值)→ `params.tau_dup`

| tau_dup | fake pass | 诚实 ROI |
|---|---|---|
| 0.90 | 0.000 | +0.48 |
| **0.95**(当前) | 0.060 | +0.58 |
| 0.98 | 0.082 | +0.60 |
| 0.99 | 0.082 | +0.60 |

**建议:保留 `0.95`;若要零 fake-pass 收紧到 `0.90`(代价:诚实 ROI 0.58→0.48)。** 越低
=去重越严=spam 越少但诚实误判略升。当前 `0.95` 平衡合理。

## 建议主网 genesis(校准后,附理由)

```toml
# 经 sim/sweep.py 敏感性扫描支撑的保守主网起始值。上线后按真实测试网数据经治理微调。
base_emission_micro   = 8000000    # 诚实 ROI 稳健正、膨胀温和(4–8 区间);配合下方衰减
decay_half_life_blocks = <引导期区块数>  # M187:随链龄弯低增发(sim 未建模,按出块率换算)
slash_bps             = 10000      # 满罚:最强攻击威慑 + 最低 fake-pass,无诚实成本
# ΔK 引擎参数(params):
#   delta_k_min = 0.05   质量门甜区下沿,绝不可再低(0 时 fake-pass 0.69)
#   tau_dup     = 0.95   近重复阈值,平衡
#   其余(c_cap/lam/bonus_max/fresh_min/n_review_min/n_min)扫描外,保留 B.2.3 默认
```

**全部 4 组参数均可经 M193–198 的链上治理(双门槛)在上线后调整**,故初值定得保守、
用数据迭代是安全的路径。

## 诚实边界(must read)

1. **方向性模型,非央行级标定**:结论对**行为假设**(攻击者策略、需求曲线、评议诚实度)
   敏感。本扫描固定了一组假设;真实主网前应**与测试网实测数据交叉校准**(白皮书 B.3.6)。
2. **种子敏感**:已对 5 种子取均值,但尾部场景(小样本冷启动)仍有方差。
3. **一次一旋钮**:未测**交互效应**(如低 base_emission × 高 slash 的联合区)。后续可做
   二维网格。
4. **sim 未建模** `decay_half_life_blocks`(M187 增发时间衰减)、桥接经济、治理攻击、
   真实需求销毁曲线——这些的参数需另行推理或扩模型。
5. **novelty 用随机单位向量代理**,未建模对抗样本攻击 ΔK 的 novelty 项(白皮书 B.2 开放
   问题)——`tau_dup`/`delta_k_min` 的真实对抗鲁棒性需链上数据验证。
6. 这些是**genesis 起始值建议**,不是"最优值证明"。治理(M193–198)是把它们上线后调优的
   机制。
